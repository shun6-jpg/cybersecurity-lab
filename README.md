# cybersecurity-lab
Hands-on cybersecurity labs using Kali Linux, Ubuntu Server, Wireshark, Suricata, and other security tools.

サイバーセキュリティとネットワークについて、仮想環境を使って実際に検証した内容を記録するリポジトリです。

## Environment / 環境

- Windows 11
- VMware Workstation
- Kali Linux
- Ubuntu Server 24.04 LTS

## Lab Network　/ 検証ネットワーク

- Kali Linux: `192.168.10.129`
- Ubuntu Server: `192.168.10.128`
- Network: `192.168.10.0/24`

## Labs / 進め方

1. ネットワークの基礎
2. ポートスキャン
3. パケット解析
4. IDS / Suricata
5. ログ解析
